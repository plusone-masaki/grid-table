# データ表示・編集機能 基本仕様

## 機能概要
文字列の2次元配列をテーブル形式で表示し、個別セルの編集を可能にする基本機能。

## 主要機能

### 1. データ表示
- **入力**: 文字列の2次元配列（`string[][]`）
- **表示**: HTMLテーブルとしてレンダリング
- **自動計算**: 行数・列数を配列から自動計算
- **データ補完**: 列数が異なる行を空文字で補完

### 2. セル選択
- **単一セル選択**: セルをクリックして選択（1×1の矩形）
- **矩形範囲選択**: ドラッグまたはShift+クリックで範囲選択
- **全選択**: Ctrl+Aで全セル選択
- **キーボード操作**: 矢印キーで選択範囲を移動・拡張

### 3. セル編集
- **編集開始**: 
  - 選択範囲の最初のセルをダブルクリック
  - F2キーを押下
  - 文字キーを直接入力
- **編集終了**:
  - Enterキー: 編集内容を保存
  - Escapeキー: 編集内容を破棄
  - 他のセルをクリック: 編集内容を保存

### 4. データ管理
- **リアルタイム更新**: 編集内容の即座な反映
- **データ整合性**: 不正な配列構造の自動修正
- **エラーハンドリング**: 無効データの適切な処理

## イベント

### 発火イベント
- `rangeSelect`: 範囲選択時
- `editStart`: セル編集開始時
- `editEnd`: セル編集終了時
- `dataChange`: データ変更時
- `error`: エラー発生時

## 設定項目

### 基本設定
- `data`: 2次元文字列配列（必須）
- `editable`: 編集可能フラグ（デフォルト: true）
- `cellHeight`: セル高さ（デフォルト: 24px）
- `cellWidth`: セル幅（デフォルト: 100px）

## パフォーマンス要件

### 基本性能
- **レスポンス時間**: セル編集から表示反映まで100ms以内
- **大量データ**: 1000行×100列程度でもスムーズな操作
- **メモリ効率**: 基本動作で100MB以下のメモリ使用量

### 巨大ファイル対応
- **ストリーミング読み込み**: データをチャンク単位で読み込み
- **仮想化レンダリング**: 表示範囲のみをメモリに保持
- **メモリ効率**: 1GBデータでも100MB以下のメモリ使用量
