# Undo/Redo機能 基本仕様

## 機能概要
ユーザーの操作を履歴として管理し、操作の取り消し（Undo）と再実行（Redo）を可能にする機能。

## 主要機能

### 1. 操作履歴管理
- **履歴記録**: 全ての操作を時系列で記録
- **履歴保持**: 最大50レベルの操作履歴を保持
- **履歴検索**: 特定の操作タイプでの履歴検索
- **履歴クリア**: 履歴の一括削除

### 2. Undo操作
- **操作取り消し**: 直前の操作を取り消し
- **段階的取り消し**: 複数回のUndo操作に対応
- **取り消し制限**: 取り消し可能な操作の制限
- **取り消し通知**: Undo操作の完了通知

### 3. Redo操作
- **操作再実行**: 取り消した操作を再実行
- **段階的再実行**: 複数回のRedo操作に対応
- **再実行制限**: 再実行可能な操作の制限
- **再実行通知**: Redo操作の完了通知

### 4. メモリ管理
- **削除データ保持**: 削除されたデータの完全な保存
- **圧縮保存**: 削除データの圧縮によるメモリ効率化
- **自動削除**: 古い履歴データの自動削除
- **メモリ監視**: 履歴データのメモリ使用量監視

## 対応操作

### テーブル構造操作
- **行の削除**: 削除された行データの完全な復元
- **列の削除**: 削除された列データの完全な復元
- **行の追加**: 追加された行の削除
- **列の追加**: 追加された列の削除

### セル編集操作
- **セル編集**: 編集前の値への復元
- **一括編集**: 複数セルの一括変更の取り消し
- **データ貼り付け**: 貼り付け前の状態への復元

### 選択操作
- **選択変更**: 選択状態の復元
- **範囲選択**: 選択範囲の復元

## イベント

### 発火イベント
- `undoAvailable`: Undo可能な操作がある時
- `redoAvailable`: Redo可能な操作がある時
- `undo`: Undo操作実行時
- `redo`: Redo操作実行時
- `historyClear`: 履歴クリア時
- `memoryWarning`: メモリ使用量警告時

## 操作仕様

### 基本操作
- `undo()`: 直前の操作を取り消し
- `redo()`: 取り消した操作を再実行
- `canUndo()`: Undo可能かチェック
- `canRedo()`: Redo可能かチェック
- `clearHistory()`: 履歴をクリア

### 履歴管理
- `getHistory()`: 操作履歴を取得
- `getHistoryCount()`: 履歴数を取得
- `setMaxHistoryLevels(levels)`: 最大履歴レベルを設定

## パフォーマンス要件

### 基本性能
- **Undo/Redo時間**: 操作の取り消し・再実行まで50ms以内
- **履歴管理**: 50レベルの履歴を効率的に管理
- **メモリ効率**: 履歴データで100MB以下のメモリ使用量

### メモリ最適化
- **圧縮保存**: 削除データの圧縮によるメモリ削減
- **遅延削除**: 古い履歴データの自動削除
- **差分保存**: 変更部分のみの保存

## 設定項目

### 履歴設定
- `maxHistoryLevels`: 最大履歴レベル（デフォルト: 50）
- `enableCompression`: データ圧縮の有効化（デフォルト: true）
- `autoCleanup`: 自動クリーンアップの有効化（デフォルト: true）
