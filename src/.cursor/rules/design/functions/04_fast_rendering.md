# 高速再描画機能 基本仕様

## 機能概要
データの変更時に高速で効率的な再描画を実現するための仮想化レンダリングと差分更新機能。

## 主要機能

### 1. 仮想化レンダリング
- **表示範囲のみ**: 表示されているセルのみをDOMに生成
- **動的更新**: スクロールに応じて表示セルを更新
- **画面サイズ連動**: 画面サイズに応じて自動的に仮想化を適用
- **スムーズスクロール**: 60FPSでの滑らかなスクロール

### 2. 差分更新
- **変更検出**: データの変更部分を自動検出
- **部分再描画**: 変更されたセルのみを再描画
- **バッチ更新**: 複数の変更をまとめて処理
- **更新最適化**: 不要な再描画を回避

### 3. 高速描画
- **DOM操作最小化**: 必要最小限のDOM操作
- **レンダリング最適化**: ブラウザの描画エンジンを効率的に活用
- **アニメーション対応**: スムーズなアニメーション表示
- **フレームレート維持**: 60FPSでの安定した描画

### 4. メモリ管理
- **効率的なキャッシュ**: 表示データの効率的なキャッシュ
- **ガベージコレクション**: 不要なオブジェクトの適切な解放
- **リソース管理**: DOM要素の効率的な管理

## イベント

### 発火イベント
- `renderStart`: 再描画開始時
- `renderComplete`: 再描画完了時
- `partialUpdate`: 部分更新時
- `performanceWarning`: パフォーマンス警告時
- `renderError`: 描画エラー発生時

## 設定項目

### 描画設定
- `batchSize`: バッチ更新のサイズ（デフォルト: 100セル）
- `animationDuration`: アニメーション時間（デフォルト: 200ms）
- `virtualizationBuffer`: 仮想化時のバッファ行数（デフォルト: 5行）

## パフォーマンス要件

### 描画性能
- **再描画時間**: データ変更から再描画完了まで100ms以内
- **部分更新**: 変更されたセルのみを50ms以内で更新
- **スクロール**: 60FPSでのスムーズなスクロール
- **アニメーション**: 60FPSでの滑らかなアニメーション

### スケーラビリティ
- **最大行数**: 10,000,000行まで対応
- **最大列数**: 1,000列まで対応
- **描画最適化**: 表示範囲外のデータは描画対象外
- **動的仮想化**: 画面サイズに応じて自動的に仮想化を適用

## データソース

### 入力データ
- **文字列配列**: メモリ内の2次元文字列配列（`string[][]`）
- **動的仮想化**: 画面サイズに応じて自動的に仮想化レンダリングを適用
- **画面サイズ連動**: 表示可能な行数を超えた分から即座に仮想化を開始
