# 範囲選択機能仕様書

## 1. 背景と狙い
- 単一セル選択に続き、ユーザーが矩形範囲を選択できるようにして、コピー・編集・スタイリングなど今後の操作の基盤を整える。
- 既存の仮想化機構・セルレンダリングを尊重し、スクロールやデータ更新時でも選択範囲が一貫して維持される実装を提供する。
- 既存で導入した `SelectionOutline` コンポーネントを再利用しつつ、範囲塗りつぶしやアンカーセル強調など複数要素をレイヤー化する。

## 2. 成功条件
- セルをドラッグ（プライマリポインタ）するとドラッグ開始セルをアンカーに矩形範囲がリアルタイムで拡張される。
- Shift + クリックで既存のアンカーから新しいセルまでの矩形が選択される。
- 選択範囲内のセルには `aria-selected="true"` が設定され、スクリーンリーダーでも範囲を理解できる。
- 選択範囲はスクロール・メトリクス再計算後も正しいセル集合を指し示し、仮想化により一時的に非表示になったセルもスクロール復帰時に正しく強調される。
- ポインタイベントがキャンセルされた場合やデータセットのサイズが変化した場合でも状態が破綻せず、安全に範囲をリセットできる。

## 3. スコープ
- 対象：ボディ領域のデータセルに対する単一範囲選択（矩形1つ）。
- 非対象：複数範囲の保持、ctrl/cmd による加算選択、タッチロングプレスのコンテキストメニュー表示、コピー／貼り付けなどの派生操作。
- 既存の単一セル選択との互換性を保ち、単一クリックは 1x1 範囲として扱う。

## 4. 用語
- **アンカーセル**：範囲選択の起点となるセル。Shift クリックでも維持される。
- **フォーカスセル**：現在範囲終端として扱うセル。ドラッグ中はポインタ下のセル、Shift クリック時はクリック対象セル。
- **範囲境界（SelectionBounds）**：`top/left/width/height` を持つ矩形。`SelectionOutline` コンポーネントに渡す。
- **選択領域セル集合**：アンカーセル・フォーカスセル間の矩形内に含まれる全セル。

## 5. UI / 視覚仕様
- 外枠・塗りつぶしともに `CellSelection` コンポーネントを拡張して描画する。`variant="outline"`（既存スタイル）と `variant="fill"`（背景色 `rgba(37, 99, 235, 0.12)`）で役割を切り替える。
- アンカーセル：行インデックスとセル背景を `grid-table__selection-anchor` クラスで強調（背景色 `rgba(37, 99, 235, 0.18)`、太字フォント維持）。
- 選択中のセルは既存の `aria-selected` に加え、`grid-table__cell--selected` クラスを付与し、背景 `rgba(37, 99, 235, 0.08)` にする。
- 選択フィル・アウトラインはスクロールコンテナ直下に配置し、`position: absolute; z-index: 18（fill）, 20（outline）` とする。

## 6. インタラクション仕様
- **ドラッグ範囲選択**：
  - `pointerdown` でアンカーセルを確定し、`event.currentTarget.setPointerCapture(pointerId)` を呼び出す。
  - `pointermove` 中はポインタ座標からフォーカスセルを解決し、矩形を更新。ポインタがセル外の場合も直近のセルにスナップ。
  - `pointerup` / `pointercancel` でキャプチャ解除し、最終範囲を確定。ドラッグ前に `event.button !== 0` なら範囲更新を行わない。
- **Shift + クリック**：
  - 前回のアンカーセルを維持し、クリック対象セルをフォーカスセルに設定する。
  - Shift + クリック時はスクロール位置に関わらず、対象セルがレンダリングされていれば即座に範囲を再描画する。
- **単一クリック**：ドラッグが発生しない場合は 1x1 範囲を選択。既存の単一セル挙動を踏襲。
- **複数インタラクション排他**：ドラッグ中は追加の `pointerdown` を無視し、完了後にのみ次の操作を受け付ける。

## 7. 状態管理
- `GridTable` 内に以下の state を保持する。
  - `activeCell: CellCoordinate | null`：アンカーセル兼現在フォーカスセル。
  - `selectionRange: { anchor: CellCoordinate; focus: CellCoordinate } | null`：現在の矩形範囲。
  - `isPointerSelecting: boolean` と `pointerCaptureId: number | null`：ドラッグ中かどうかとキャプチャ中の pointerId。
- 範囲更新はヘルパー `normalizeRange(anchor, focus)` を通じて `topRow/bottomRow/leftColumn/rightColumn` を算出。
- 仮想化関係：
  - `selectionRange` は常に絶対座標（データセット基準）で保持し、スライスやスクロールに依存しない。
  - 可視セル描画時は、範囲内部かを `rowIndex` / `columnIndex` で判定して `aria-selected` とクラス付けを行う。
- データ変化時（行削除・列削除など）にアンカーまたはフォーカスが範囲外になった場合は `selectionRange = null`、`activeCell = null` にリセット。

## 8. DOM 構造とレイヤー
```
div.grid-table__scroll (relative)
 ├─ CellSelection variant="fill"  (absolute)  ※範囲がある時のみ
 ├─ CellSelection variant="outline" (absolute)
 └─ 既存の grid-table__spacer 群
```
- 塗りつぶし・アウトラインともに `transform: translate(-1px, -1px)` を適用してセル境界と一致させる。
- 位置・サイズは `SelectionBounds` を用いて一元的に計算し、両方のレイヤーに適用する。
- 重なり順は DOM の描画順に従う。オーバーレイはデータテーブルより後、ヘッダー・行番号より前に挿入して視覚的階層を制御する。
- 複数の描画要素を生成する際は `CellSelection` の variant を切り替えて再利用し、ロジック重複を避ける。

## 9. アクセシビリティ
- 範囲内のセルすべてに `aria-selected="true"` を付与し、範囲外セルからは除去する。
- 今後のキーボード操作を見据えて `activeCell` を `tabIndex={0}` にする準備を整え、今回は `tabIndex={-1}` でフォーカス移譲を回避する。
- 塗りつぶし要素・アウトライン要素は `aria-hidden="true"` とし、支援技術には報告しない。

## 10. エッジケースと動作要件
- `EMPTY_DATASET_FALLBACK` 使用中は範囲選択を無効化し、`selectionRange` は常に `null`。
- 行または列が 0 の場合はアンカー設定も許可しない。
- ドラッグ中にポインタがキャンバス外へ出た場合でも、キャプチャによりドラッグ継続を保証。`pointercancel` 受信時は確実に終了処理を行う。
- 連続して同一セルをドラッグ開始→終了した場合、単一セル範囲として扱い、余分なイベント発火を避ける。
- レンダリングされていないセル（仮想化領域外）をフォーカスに指定するときは、範囲計算を許可しつつ描画は行わない。

## 11. テスト戦略
- **レンダリング**：初期表示で `grid-table__selection-outline` / `grid-table__selection-fill` が存在しないことを確認。
- **ドラッグ操作**：ユーザ操作テストでドラッグ開始→移動→終了の各段階で範囲が更新され、アウトライン・フィルの位置とサイズが期待値と一致すること。
- **Shift + クリック**：単一セル選択後に Shift + クリックで矩形が正しく拡張されること、アンカーセルが更新されないことを検証。
- **仮想化**：スクロールでアンカーセルが非表示→再表示になった際に範囲が復元され、可視セルのみ `aria-selected` が付与されること。
- **データ更新**：行削除や列削除後に範囲が自動的にリセットされ、アウトライン/フィルが DOM から除去されること。
- **キャンセル処理**：`pointercancel` / `pointerup` が呼ばれた場合に pointer capture が解除され、内部 state がドラッグ前に戻ること。

## 12. 今後の拡張余地
- 複数範囲サポート（Ctrl/Cmd + クリック）と範囲マージ操作。
- 選択ハンドル（右下の小さなスカッシュ）によるドラッグ拡張。
- キーボードナビゲーション（Shift + 矢印キー）や `aria-activedescendant` の導入。
- 範囲選択後のコピー／貼り付け、削除、スタイリング操作との連携。
